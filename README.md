# SIGEPAI-IEE Landing Page

Standalone responsive landing page for SIGEPAI-IEE Soluciones Académicas.

## Run locally

Open `index.html` directly in a modern browser. No build step, package manager, external assets, or server is required.

## Files

- `index.html` — semantic Spanish landing-page content
- `styles.css` — responsive editorial visual system
- `script.js` — accessible mobile-navigation toggle and footer year
